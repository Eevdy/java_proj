## Описание проекта
Данный проект представляет собой реализацию модели банковского счёта (`BankAccount`) на языке Java со строгим соблюдением ООП-принципов и практик написания надёжного кода.

### Основные компоненты:
* **`Currency`** - перечисление поддерживаемых валют (`RUB`, `USD`, `EUR`, `CNY`) со стоимостью одной единицы в российских копейках.
* **`Balance`** - неизменяемый (`immutable`, `final`) класс для хранения денежных средств в копейках/минимальных единицах и валюте. Поддерживает операции сложения, вычитания и конвертации между валютами.
* **`BankAccount`** - банковский счёт с операциями пополнения, снятия и перевода средств между счетами:
  * Лимит на разовый вывод/перевод (`withdrawalLimit`).
  * Статус счёта (`AccountStatus.ACTIVE`, `AccountStatus.BLOCKED`) с возможностью блокировки и разблокировки.
* **Пользовательские исключения** в пакете `exception`:
  * `InsufficientFundsException` - при нехватке средств на счёте;
  * `LimitExceededException` - при превышении лимита операций;
  * `AccountBlockedException` - при попытке провести операцию с заблокированным счётом.
* **`Main`** - подробная демонстрация работы системы и обработки всех граничных случаев.
